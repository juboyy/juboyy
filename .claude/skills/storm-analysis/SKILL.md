# STORM Analysis Skill

Baseado no Método STORM de Stanford (*Synthesis of Topic Outlines through
Retrieval and Multi-perspective Question asking*). Princípio central:
**não analise sob um ângulo só — interrogue o tema sob 5 perspectivas de
especialistas diferentes e depois sintetize.** Gera resultado mais completo
e organizado do que uma análise linear.

## Quando usar
- Análise de status/performance de campanhas de anúncios (Meta, Google, TikTok…).
- Avaliação de uma oferta, produto, preço ou criativo.
- Qualquer decisão estratégica em que faltem ângulos ("vale a pena?", "o que está errado?").

## Como aplicar

1. **Colete os dados reais primeiro.** Nunca analise de memória. Para marketing,
   use as ferramentas do Supermetrics MCP (status de campanha, conjuntos, anúncios,
   gasto, conversões) antes de opinar. Verifique o nível do anúncio, não só o da
   campanha (uma campanha "ativa" pode não entregar se os anúncios estão pausados).

2. **Analise sob as 5 lentes** (adapte os nomes ao contexto):
   - 🎯 **Operacional / Media buyer** — o que mecanicamente trava ou destrava a
     entrega agora (status de anúncio, orçamento, pixel, aprovação).
   - 🔬 **Cético** — qual o contra-argumento mais forte? O que pode dar errado mesmo
     se tudo "parecer certo"? (limitações de alcance, políticas, saturação).
   - 💰 **Economista** — quem lucra e quais são as contas? Unit economics, CMV,
     CPA-alvo vs. margem real. Aponte conflitos entre meta e realidade.
   - 📜 **Histórico** — que padrões os dados passados revelam? (testes curtos,
     campanhas arquivadas, sazonalidade, o que já funcionou ou falhou).
   - 📐 **Acadêmico / Evidência** — o que os dados *permitem* afirmar? Sinalize quando
     a amostra é pequena demais para conclusões; exija tracking confiável.

3. **Sintetize.** Feche com um parágrafo de síntese que reconcilia as 5 lentes e uma
   lista curta de **ações priorizadas** (o que fazer primeiro e por quê).

## Regras
- Baseie-se só em dados reais das ferramentas; rotule estimativas claramente.
- Seja direto: aponte conflitos (ex.: meta de margem incompatível com produto físico).
- Cada lente deve trazer um insight distinto — não repita o mesmo ponto reescrito.
- Termine sempre com próximos passos acionáveis, não só diagnóstico.
