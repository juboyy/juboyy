## Método (5 regras)

1. **Spec assinada antes de código.** Sem spec, sem sprint.
2. **Teste obrigatório em toda entrega.** Cobertura definida no contrato.
3. **Revisão sênior em 100% dos PRs.** Orquestrador humano assina o delivery.
4. **Ambiente isolado por cliente.** Dados não treinam modelo de terceiros.
5. **Vault de memória em git.** Sem vendor lock-in — se AUMI sumir, o cliente fica com tudo.

<sub>Modelo é model-agnostic: Claude, Gemini, Llama, Qwen. Detalhes em <a href="https://aumi.group/blog/o-que-e-ai-native/">O que é AI Native</a> e <a href="https://aumi.group/blog/agentes-de-ia-em-producao/">Agentes de IA em produção</a>.</sub>
