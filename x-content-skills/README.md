## Como portar para o seu repo local (Windows)

No `C:\Users\blzja\Documents\x-content-skills-repo`, crie as pastas `calendar/`,
`data/` e `scripts/` e copie os 3 arquivos. Depois:

```bash
git add calendar data scripts
git commit -m "Semana 1: calendario, leads e radar"
```

## Relação com o ViralForge

No repo `juboyy/juboyy` (branch `claude/x-account-monetization-8xdfc7`) há o **ViralForge**:
um app que pontua cada post com um Viral Score (8 parâmetros) e gera variações com Claude.
Use-o para **filtrar os posts da Semana 1 antes de publicar** — cole cada post no analisador
e suba o score antes de ir pro ar.
